sparemine 설정 생성기

BTC 수신 주소와 몇 가지 옵션을 넣으면, 내 컴퓨터에서 바로 실행할 한 줄 명령, config.toml, 실행 스크립트를 만들어 줍니다. 플랫폼마다 설정을 손으로 고칠 필요 없이, 채우고 복사하면 끝입니다.

지급받을 지갑

넣는 것은 공개 수신 주소뿐입니다. sparemine은 개인키나 시드 문구를 요구하지도, 저장하지도, 전송하지도 않습니다. 이 주소는 브라우저 밖으로 나가지 않고, 아래 명령에 글자로만 들어갑니다.

무엇을, 어디서, 어디에

자원 사용 (남는 만큼만)

스레드 수를 넣으면 CPU 상한 대신 그 수가 쓰입니다. 기본값은 "방해하지 말 것"에 맞춰져 있어요.

처음 넣어 둔 값은 예시입니다. 내 설정으로 바꿔 보세요.

실행할 것

① 한 줄 명령

내려받기 · 실행 권한 · 실행을 한 번에. 터미널(또는 PowerShell)에 붙여넣으세요.

② config.toml

바이너리와 같은 폴더에 두고 sparemine --config config.toml 로 실행합니다.

③ 실행 스크립트

파일로 저장해 두고 쓰고 싶을 때. 내려받기 → 내용 확인 → 실행.

하드웨어부터 확인하려면:

sparemine은 브라우저가 아니라 내 컴퓨터에서 도는 네이티브 채굴기입니다. 이 페이지는 채굴을 하지 않고, 내가 실행할 명령과 설정 파일을 만들어 줄 뿐입니다. 웹페이지가 방문자 브라우저에서 몰래 채굴하는 방식(cryptojacking)이 아닙니다.

남의 전기·하드웨어를 쓰는 일이 없도록, 내 컴퓨터나 소유자가 동의한 컴퓨터에서만 실행하세요. PC방·사무실 PC처럼 내 것이 아닌 기기에서 돌리는 것은 그 장소의 약관을 어기는 일일 수 있고, 잠금을 우회해 설치하는 것은 더 분명한 법적 문제입니다. (법률 자문이 아닙니다.)

넣은 값은 이 브라우저에만 저장되고 어디로도 보내지 않습니다. 바이너리는 GitHub Releases에서 받습니다. 쓰는 법은 sparemine README에 있습니다.
